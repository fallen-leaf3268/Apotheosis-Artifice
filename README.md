# Apotheosis Artifice

Apotheosis Artifice 是 fallen-leaf3268 开发的非官方 Apotheosis 附属模组。它扩展饰品重铸、宝石存储、附魔台、便携回收和其他模组兼容功能。需要安装 Apotheosis；本项目不代表 Apotheosis 原作者。

## 版本与依赖

当前版本为 1.0.8，目标环境为 Minecraft 1.20.1 / Forge 47.x。

构建使用 Apotheosis 7.4.8、Placebo 8.6.2、Apothic Attributes 1.3.5 和 Curios 5.14.1+1.20.1。运行时还需要这些前置模组各自要求的依赖。前置模组通过各自的官方渠道安装。

## 更新内容（相对已发布的 1.0.8）

- 重绘宝石柜界面、普通宝石柜和法贝热宝石柜，优化栏位边框、按钮状态与物品辨识。
- 更新渡鸦附魔台、机械渡鸦附魔台的方块、GUI 与魔法书材质，修正世界中的书本材质显示。
- 优化两种附魔台的属性条和滑块，修正界面名称、文字对齐与滑块点击范围。
- 重绘神化重铸台、锻锤与重铸界面。
- 修复输入 `E` 键时误关闭界面的问题。
- 两种附魔图书馆打开时不再自动聚焦搜索栏，可直接按背包键退出。
- 优化宝石输出栏翻页布局，按所选宝石支持的最高等级显示按钮。
- JEI 词缀和宝石详情增加数据来源提示，改善多行说明显示。
- 优化机械渡鸦附魔台的输入、附魔和输出流程。
- 修复机械渡鸦附魔台的 JEI 配方填充与 Shift 整组填充，物品进入输入缓存栏，并返还原附魔栏物品。
- 新增 Jade 红石激活状态与自动附魔缺少青金石提示。
- 修复渡鸦附魔台在生存模式下通过 JEI 填充配方时，属性滑块未自动调整的问题。
- 新增天青书架与知识满溢书架，为三种附魔台提供最多3级青金石减免及100%经验点减免，附魔要求等级不变；两种书架均可通过工作台合成。
- 机械渡鸦自动附魔与灌注基础恢复为消耗3个青金石，可由书架减免；并新增附魔间隔可配置，默认20 tick。
- 清除符石完整移除重铸数据，仅允许对带有神化数据或残留标签的物品使用。
- 新增圣洁布匹，可在物品栏中移除目标物品的全部诅咒并保留其他附魔。
- 刷怪笼新增初始生命值、燃烧和回响属性，以及四种预设升级符文；预设造成降级时首次提示，重复使用确认后执行。
- 新增至高符石与恶意符石；升级原有末影拴绳，并新增秘法末影拴绳。
- 修复神化模块关闭时的旧装备事件、配方和附魔标签兼容问题。
- 新增饰品重铸开关，默认开启；关闭后停止饰品重铸及相关战利品生成，已有词条继续生效，重启后应用。
- 改善重铸与附魔的扩展方式，修复与 Apothic Infinite 共用词条显示时的启动冲突，并兼容 Apothic Attributes 不同版本的护甲计算接口。
- 附魔增强以神化的等级上限配置为基础，只在运行时提高；将本模组位阶上限调回神化原范围后恢复基础上限与威力曲线，增强结果不写入神化配置。
- 补全许可声明和项目说明。
