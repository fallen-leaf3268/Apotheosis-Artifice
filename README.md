# Apotheosis Artifice

Apotheosis Artifice 是 fallen-leaf3268 开发的非官方 Apotheosis 附属模组。它扩展饰品重铸、宝石存储、附魔台、便携回收和其他模组兼容功能。需要安装 Apotheosis；本项目不代表 Apotheosis 原作者。

## 版本与依赖

当前版本为 1.0.8，目标环境为 Minecraft 1.20.1 / Forge 47.x。

构建使用 Apotheosis 7.4.8、Placebo 8.6.2、Apothic Attributes 1.3.5 和 Curios 5.14.1+1.20.1。运行时还需要这些前置模组各自要求的依赖。前置模组通过各自的官方渠道安装。

## 附魔书架数据包配置

书架属性统一使用 Apotheosis 的 `data/<namespace>/enchanting_stats/<filename>.json` 配置。在同一份文件的 `stats` 对象内，可按需配置位阶、量子化、阿卡那、青金石减免和经验点减免。两项减免字段均可选，省略时为 `0`；原生普通书架 JSON 无需新增这些字段。

默认有效数值如下，省略的减免字段按 `0` 计算。`experience_discount` 的单位为百分比，`25` 表示减免 25% 经验点：

| 书架 | `maxEterna` | `eterna`（位阶） | `quanta`（量子化） | `arcana`（阿卡那） | `lapis_discount` | `experience_discount` |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 天青书架 | 0 | -2.5 | 7.5 | 7.5 | 1 | 0 |
| 知识满溢书架 | 50 | 4 | 5 | 5 | 0 | 25 |

默认 JSON 可直接参考：

- [天青书架](src/main/resources/data/apotheosis_artifice/enchanting_stats/lapis_shelf.json)。
- [知识满溢书架](src/main/resources/data/apotheosis_artifice/enchanting_stats/knowledge_overflow_shelf.json)。

调整默认书架时，在优先级更高的数据包中放置同资源 ID 的文件，例如 `data/apotheosis_artifice/enchanting_stats/lapis_shelf.json`，知识满溢书架则使用 `knowledge_overflow_shelf.json`。同 ID 覆盖替换的是整个 JSON，覆盖时请保留需要的原生属性、减免字段和模块条件。文件不需要顶层 `type` 字段。天青书架的负位阶遵循 Apotheosis 原生计算规则，可能被其他书架的富余贡献抵消。

为其他方块配置属性和减免时，可使用自己的 namespace 和任意文件名。例如在 `data/my_pack/enchanting_stats/bookshelf.json` 中仅配置青金石减免，经验点减免省略为 `0`：

```json
{
  "block": "minecraft:bookshelf",
  "stats": {
    "maxEterna": 15,
    "eterna": 1,
    "quanta": 0,
    "arcana": 0,
    "lapis_discount": 1
  },
  "conditions": [
    {
      "type": "apotheosis:module",
      "module": "enchantment"
    }
  ]
}
```

目标方块沿用原生 `block`（单个已注册方块资源 ID）、`blocks`（方块资源 ID 数组）或 `tag`（方块标签资源 ID）格式。`stats` 内的 `lapis_discount` 和 `experience_discount` 是可独立省略的整数，省略时为 `0`，合法范围分别为 `0..3` 和 `0..100`；25% 经验点减免应填写 `25`，不能填写 `0.25`。附魔环境内各方块的减免合计仍最多为 3 级青金石减免和 100% 经验点减免，附魔要求等级不变。

不同资源 ID 作用于同一个方块时，减免不会叠加；按资源 ID 字符串的字典顺序排序后，最后一份定义生效，并在日志中记录警告。调整已有定义时推荐覆盖相同资源 ID。

服务器执行 `/reload` 后，减免数据会自动同步到客户端；正常重新打开附魔菜单即可读取新数据。
