# EasyMagic 刷新按钮 UI 兼容设计

## 目标

为神化附魔台、渡鸦附魔台和机械渡鸦附魔台提供可用且不重叠的 EasyMagic 刷新按钮。保持现有 `id = 4` 菜单协议和服务端刷新逻辑不变。

## 布局

- 刷新按钮统一放在神化界面主体左侧，横坐标为 `leftPos - 40`，纵坐标保持 `topPos + 16`。
- 按钮尺寸保持 EasyMagic 原版的 `38 × 27`，继续使用其正常、悬停和禁用三种纹理状态。
- 不隐藏或覆盖神化界面的书本、附魔槽、位阶、量子化、阿卡那属性条。
- 专用刷新催化剂配置启用时，槽位仍使用现有菜单布局；本次不重新设计槽位材质。

## 交互

- 鼠标命中区域与绘制区域使用同一个坐标方法，避免可见位置和实际点击位置不一致。
- 点击后继续调用客户端菜单的 `clickMenuButton(player, 4)`；成功时发送容器按钮包并播放附魔台音效。
- 不改变刷新所需的经验、催化剂数量及服务端校验。
- 按钮不可用时保留禁用纹理，并在提示中展示刷新成本。

## 本地化

- 新增本模组翻译键 `gui.apotheosis_artifice.enchant.reroll`。
- `zh_cn` 显示“刷新附魔选项”。
- `en_us` 显示“Reroll Enchantments”。
- 工具提示不再依赖 EasyMagic 缺失的中文语言文件。

## 验证

- 源码回归测试确认所有神化附魔界面均使用外置坐标。
- 测试确认工具提示引用本模组翻译键，且中英文资源均包含该键。
- 全量运行 `clean test build`，确认 Mixin 编译、测试和重混淆 JAR 构建成功。
- 游戏内检查普通神化、渡鸦和机械渡鸦界面：按钮无重叠、提示已翻译、点击后附魔选项刷新。

## 非目标

- 不修改珍珠启用宝藏附魔的条件。
- 不修改量子化、阿卡那或位阶计算。
- 不修改机械自动附魔。
- 不把 JAR 自动部署到实例的 `mods` 目录。
