# EasyMagic 刷新按钮贴边与原生图标设计

## 背景

当前 Apotheosis 附魔界面的 EasyMagic 刷新按钮位于 GUI 左侧，但按钮右边缘与 GUI 左边框之间保留了 2 像素空隙。兼容层只绘制了 EasyMagic 的 38×27 按钮底板，没有继续绘制原版按钮的刷新图标和消耗信息，因此游戏中显示为一块近似空白的悬浮底板。

## 目标

- 采用已确认的方案 A：按钮在左侧中上位置贴合 GUI 边框。
- 复用 EasyMagic 自带纹理，恢复原版刷新图标和消耗显示。
- 保持现有点击协议、刷新逻辑、工具提示和翻译键不变。
- 不新增材质，不修改 Apotheosis 的问号按钮。

## 布局

按钮尺寸保持 38×27 像素。横坐标从 `leftPos - 40` 调整为 `leftPos - 38`，使按钮右边缘与 GUI 左边框重合。纵坐标继续使用 `topPos + 16`，保持与附魔书区域对应的中上位置。

## 绘制

兼容层继续使用 `easymagic:textures/gui/container/enchanting_table_reroll.png`，并按照 EasyMagic 8.0.1 的原生分层顺序绘制：

1. 根据不可用、不可负担、普通和悬停状态绘制按钮底板。
2. 当刷新功能可用时，绘制 15×15 的刷新图标，并使用原版的禁用、普通和悬停纹理状态。
3. 根据 EasyMagic 配置的经验值与催化剂消耗，在按钮内绘制相应消耗球和数字；两种消耗同时存在时分别占据上下位置，只有一种消耗时居中显示。

所有数值继续由 `EasyMagicCompat` 读取，客户端显示与服务端实际扣除使用同一配置来源。创造模式和资源不足时沿用 EasyMagic 原版的状态颜色。

## 交互

点击命中区域随新横坐标同步移动，仍为 38×27 像素。菜单按钮编号保持为 `4`，声音、服务端刷新流程、悬停提示以及 `container.enchant.reroll` 翻译键均不改变。

## 兼容边界

- EasyMagic 未加载或关闭刷新功能时不绘制按钮。
- 不改变普通附魔、机械渡鸦自动附魔、珍宝附魔启用条件以及神化的永恒、量子化和阿卡那属性。
- 专用刷新催化剂槽的材质绘制保持现状。
